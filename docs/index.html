About this snapshot

The paired C+ example uses the 125,000-update checkpoint at NFE 1, 5, 20, and 100. The eight author-demo examples retain their 107,713-update checkpoint at NFE 1, 20, 50, and 100. Within each example, the checkpoint and starting noise stay fixed. Original relative levels are the default; optional RMS matching changes playback gain only.

This is an independent, experimental implementation using offline WavJEPA conditioning. C+ includes a clean reference and single-clip STOI scores; it is not a validation-set result. The other eight recordings come from the paper authors’ demo and have no clean references. More steps do not necessarily mean better speech.

About this snapshot

All restored clips use the same checkpoint and the same starting noise within each example. Only NFE changes. Audio is presented at its saved relative level; individual outputs are not loudness-normalized.

This is an independent, experimental implementation using offline WavJEPA conditioning. More steps do not necessarily mean better speech. The C+ clip has a clean reference; the windy recording does not.

Audio and spectrogram details

Window-normalized log-magnitude STFT spectrograms, with a shared reference magnitude of 1.
